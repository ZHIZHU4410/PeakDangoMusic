### 雷霆管理器：本地手动安装

使用 Thunderstore Mod Manager（雷霆管理器）时，将插件安装到**当前配置文件夹**。

1. 退出 PEAK，在雷霆管理器中选择 **PEAK → 要使用的配置（Profile）**，确认该配置已安装 `BepInExPack_PEAK`。
2. 打开 **Settings（设置）→ Browse profile folder（浏览配置文件夹）**，进入其中的 `BepInEx/plugins`。找不到入口时可在设置中搜索 `profile`。[官方配置文件夹说明](https://wiki.thunderstore.io/sharing-your-mods/modpacks-and-profiles)
3. 从完整安装包解压后的 `BepInEx/plugins` 中，将 **`PeakDangoMusic.dll` 和整个 `PeakDangoMusic` 文件夹一起复制**到该目录。文件夹中的 `Native`、`Folia` 及其所有文件都要保留。使用本机已更新的版本时，也可以从游戏目录的 `BepInEx/plugins` 复制这两项。
4. 已装旧版时，先将旧插件备份到配置文件夹之外，再替换；检查 `plugins` 的其他子文件夹，避免保留重复的 `PeakDangoMusic.dll`。已有 `BepInEx/config` 中的歌词配置可以保留。
5. 返回雷霆管理器，点击 **Start modded（启动模组游戏）**。本地新版通过游戏 **选项 → 悬浮歌词 → 打开设置** 进入菜单。

最终目录结构：

```text
当前配置文件夹/
└─ BepInEx/
   └─ plugins/
      ├─ PeakDangoMusic.dll
      └─ PeakDangoMusic/
         ├─ Native/
         └─ Folia/
```

不要只复制 DLL，也不要把完整安装包的外层目录直接放进 `plugins`。包内“一键安装.cmd”用于游戏目录安装；使用雷霆配置时请按上述步骤复制。手动复制的插件可能不会显示在管理器的模组列表中，是否加载可查看该配置的 `BepInEx/LogOutput.log`。本方式尚未在管理器中实测。

## Folia全部15种歌词样式

歌词设置右侧切换“Folia歌词样式”，可选商籁、凝彩、绘光、花火、流光、心象、云阶、浮名、倾诉、回环、莫奈、时计、群唱、镜台、静止，以及每首随机。Dango原样式仍为默认；播放器连接及已有显示参数保留。

## BLF / LX 连接

1. 在播放器设置中开启“开放 API”本机服务，默认端口23330。
2. 正常播放带歌词歌曲。歌词设置 左侧选“BLF / LX”，填写相同端口并点“应用端口”。
3. 模组只访问127.0.0.1的 /status 和 /lyric-all。播放器 exe 路径可留空，仅影响启动播放器按钮。
4. 主菜单、机场和地图均可显示；菜单、加载和设置界面自动使用屏幕浮层，回到游戏时恢复两侧世界歌词。纯音乐或无同步歌词歌曲不会显示旧歌词。

## 原版网易云音乐连接（新增，未实测）

1. 正常启动原版网易云并播放歌曲，在 歌词设置 左侧选择“原版网易云”。
2. 组件优先读取 Windows 媒体会话提供的曲名与时间；不需要账号、Cookie 或第三方网易云 API 服务。
3. 部分原版客户端不提供有效播放进度。此时先从托盘完全退出网易云，双击本包“启动网易云歌词连接.cmd”，选择自己的 cloudmusic.exe，然后正常播放。
4. 该脚本仅给当前进程添加127.0.0.1本机连接端口9223，不修改播放器文件或系统设置。已经运行的播放器不会被结束；直接启动的新参数无法接管旧进程。
5. 模组读取已知原版客户端页面的播放状态、曲目和进度，再从 music.163.com 的公开 HTTPS 接口获取歌词；不调用登录、Cookie、账号或歌曲下载接口。
6. 自定义端口时，通过脚本 -Port 参数和配置“网易云本机端口”设置相同值。
7. 播放器内部结构、公开接口或歌曲匹配不确定时会显示状态提示；不伪造进度，不用其他录音的歌词代替。

**此新增网易云连接按用户要求仅做源码接入与编译，未启动播放器或执行接口测试。** 不能保证所有原版网易云版本可用；本机接口解析沿用已有 DangoMusic 的客户端结构适配。

## 故障排查

| 现象 | 处理 |
|---|---|
| 歌词设置入口未出现 | 重开游戏，确认日志加载当前 PeakDangoMusic 版本，检查实际配置目录和重复DLL。 |
| 左侧显示未连接 | BLF/LX 开启开放 API；网易云选对来源，必要时用本包连接脚本启动。 |
| 缺少网易云组件 | 完整安装 DLL 和 PeakDangoMusic 文件夹，不要只更新 DLL。 |
| 有曲名无歌词 | 歌词设置 查看同步歌词行数、当前歌词和渲染方式；主菜单与机场也能显示。检查「启用漂浮歌词」开关、播放器进度及是否已到第一句。 |
| 中文方块或无字 | 左侧点“重新加载歌词字体”，检查本机语言字体；SDF失败会尝试兼容字体。 |
| 移动时看不到歌词 | 开启“跟随视角”；关闭人物后景，或开启允许穿墙。 |
| 光晕不明显 | 调高文字亮度；原生兼容字体的发光能力取决于系统材质。 |

日志：实际配置的 BepInEx/LogOutput.log。配置：BepInEx/config/local.peak.dangomusic.cfg。反馈只需相关片段，不要分享账号资料或播放器用户目录。
