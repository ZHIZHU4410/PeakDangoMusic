# PeakDangoMusic 2.3.0 · 安装说明

退出PEAK后完整解压安装包，运行“一键安装.cmd”选择PEAK.exe；手动安装把BepInEx/plugins下的PeakDangoMusic.dll和整个PeakDangoMusic文件夹复制到游戏对应位置。新Muonium组件与既有Folia组件都要保留，用户不需要安装Java。

雷霆管理器：选择PEAK/Profile，安装BepInExPack_PEAK，Settings → Browse profile folder，复制DLL和完整组件文件夹到该Profile的BepInEx/plugins，再Start modded。避免重复DLL。

入口：主菜单右下角“音乐播放器”，或游戏选项 → 音乐播放器 → 打开播放器。选择原生网易云/QQ或GD聚合，搜索并点击歌曲。账号中心用对应手机App扫码确认；账号权限制约继续有效。

旧CMD启动播放器与本机接口流程已停用，不需要打开外部音乐播放器。升级后旧Native组件不再启动，保留在备份中即可。音乐与歌词开关互相独立，地图歌词在侧栏“悬浮歌词”设置。

普通配置local.peak.dangomusic.cfg可以保留；账号文件PeakDangoMusic-Accounts.dpapi由Windows当前用户加密，不可迁移到他人账号；本地收藏/历史/队列保存在PeakDangoMusic-Library.json。不要分享这两类个人文件。

退出游戏后运行“卸载播放器.cmd”卸载运行组件；普通与账号配置文件由用户自行决定保留。更多功能和验证范围见README.md、VERIFICATION.zh-CN.md；版本变化见CHANGELOG.md。
