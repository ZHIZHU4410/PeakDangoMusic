# 2.3.5 歌单、登录、评论修复

- 胶囊在未播放时也绘制，标题显示未播放及右Shift入口；反斜杠保持可见性切换。完整播放器与胶囊互斥。
- QQ个人歌单从账号主页读取自建/收藏列表，并尝试创建歌单接口；未登录明确拒绝，空列表不再无限显示加载中，提供重试。
- QQ登录选择QQ或微信两条独立二维码流程。微信采用MuoniumPlayer的QQWechatLogin原服务，新增HTTP传输适配；qqLoginType随凭证DPAPI保存，业务请求带微信类型。手动Cookie仍作为备用方式。
- 酷狗按cloud/global_collection_id、user/listid、special/specialid区分，分别查询云歌单、账号文件列表和精选歌单；云/用户列表最多5000首，避免原先把云ID传给special接口。
- 评论按原平台和歌曲ID路由，网易云/QQ/酷狗/哔哩哔哩各用对应接口，不按同名曲跨平台匹配。其他未适配平台显示未接入提示。
